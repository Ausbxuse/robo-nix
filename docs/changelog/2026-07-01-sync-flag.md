# `robo shell --sync`

## Problem

Profile metadata such as `pythonGroups` and `pythonExtras` is exported into the
runtime shell, and the uv wrapper can use it when the user runs `uv sync`.
However, entering a profile shell does not perform that sync, so a correctly
declared profile can still feel incomplete until the user knows the exact sync
command to run.

## Change

- Add an explicit `--sync` option to `robo shell` and `robo run`.
- Keep uv as the owner of package installation and lockfile behavior.
- Run `uv sync --locked` after the Nix runtime environment is resolved and
  before launching the shell or child command.
- Use the generated runtime environment, so the existing uv wrapper applies
  `ROBO_NIX_PYTHON_GROUPS`, `ROBO_NIX_PYTHON_EXTRAS`, and
  `UV_PROJECT_ENVIRONMENT`.
